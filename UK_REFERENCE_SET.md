# UK reference set — principles only

All pages were accessed as public references on 2026-08-29. They are not templates, assets, code sources or copy sources. The goal is to extract one bounded principle per reference and explicitly reject copying.

| Reference | What is publicly shown | Principle usable for City Glass | Do not copy |
|---|---|---|---|
| [Geo Glaze](https://www.geoglazeltd.co.uk/) | Bespoke architectural glass, service grouping, a concise process and case-study pathway | Pair a short service selection with an understandable journey from project need to enquiry | Images, project copy, architectural tone, layouts or case studies |
| [Precision Glassworks](https://precisionglassworks.co.uk/home) | Made-to-measure systems, safety/precision proof and free-quote route | Give each proof item a practical buyer meaning: measured/surveyed, fit-for-purpose, local contact | Claims, supplied statistics, system imagery, copy and UI |
| [Vogue Glass](https://www.vogueglass.co.uk/) | Bespoke glazing portfolio, audience cues for designers/developers/home improvers | Use a restrained portfolio rhythm that distinguishes decorative/bespoke glass from ordinary window work | Brand, testimonials, service wording, imagery, typography and code |
| [TGP Glass](https://tgpglass.co.uk/) | Clear category hierarchy and a simple staged custom-glass journey | Explain “choose the type → discuss the job → get tailored advice/quote” in original language where factually appropriate | Ecommerce interaction, configurator, pricing, product taxonomy, imagery and copy |
| [Aston Glass & Glazing](https://astonglass.co.uk/) | Survey-led reassurance, UK-made/specialist framing and tailored service | A pre-quote survey can be a useful factual next step if City Glass has verified it; do not assert it as a capability before confirming | Credentials, guarantees, claims, testimonials, layouts or brand assets |

## Mapping to the potential concept

| Proposed concept element | Reference-derived abstract principle | Originalisation / risk control |
|---|---|---|
| Hero | First screen tells the visitor what kind of glazing work is relevant | Original headline and compositional system; never reuse a competitor’s words or visual frame. |
| Service slice | Group by customer job rather than a long product menu | Retain only City Glass services verified in `BUSINESS_FACTS_AND_SOURCES.md`. |
| Proof | Explain practical proof in short, scannable units | Use no unverified claim, certification or competitor-style badge. |
| Bottom 40% | Give a useful next step, not a generic oversized CTA | End with service-area/contact facts already verified and link only to the existing City Glass contact page in an authorised concept. |

No reference code, copy, Logo, photograph, icon, font file or distinctive interface pattern is authorised for reuse.
